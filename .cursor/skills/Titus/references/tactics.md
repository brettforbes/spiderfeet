# Titus Strategies and Tactics

## Workflow sequence

1. Baseline scan.
2. Filter high-risk detector classes.
3. Validate context and deduplicate.
4. Convert validated findings to nugget arrays.
5. Remediate and re-scan.

## Practical tactics

- Use changed-file scans in CI.
- Phase scans for very large repositories.
- Track recurring detector classes as process gaps.
