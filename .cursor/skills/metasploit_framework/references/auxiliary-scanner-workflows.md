# Auxiliary Scanner Workflows

Recommended sequence:

1. Select workspace
2. `search scanner` / `search auxiliary`
3. `use auxiliary/scanner/...`
4. `set RHOSTS` and required options
5. `run`
6. Review DB tables
7. Correlate with Nmap/Nuclei/Nerva outputs

Prefer this pathway for SpiderFeet graph-building and legal-safe defaults.
