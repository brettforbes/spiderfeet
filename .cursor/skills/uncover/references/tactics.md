# uncover Tactics and Workflows

## Workflow: Focused Provider Search

1. Start with one provider and narrow query.
2. Parse host/port hits.
3. Validate top findings live.

## Workflow: Multi-provider Correlation

1. Re-run equivalent query across engines.
2. Merge by host:port key.
3. Increase confidence for cross-provider matches.

## Workflow: Continuous External Exposure Monitoring

1. Run scheduled uncover queries.
2. Diff against previous finding set.
3. Alert on net-new high-risk exposure.

## Tactics

- Narrow queries reduce noise.
- Correlation improves confidence.
- Validation converts leads into evidence.
